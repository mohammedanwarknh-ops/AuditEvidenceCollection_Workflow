# AuditEvidenceCollection_Workflow
IBM Concert Audit Evidence collection Workflow.
IBM Workflow
	1. Login to IBM Concert.
	2. Go to Automation Center Panel.
	3. Start Audit Evidence collection Workflow.
	4. Select/Import CI Samples.
	5. select the Controls, Default ALL
  6. Enter the email address the output to be shared with.
	6. Submit the request.
	7. Email will be sent with ZIP file Hashed with the output
